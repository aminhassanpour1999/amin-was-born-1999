# Artwork design

- Exact phrase: **AMIN WAS BORN**
- Year represented: **1999**
- Grid: 52 columns × 7 rows
- Rows: Sunday and Saturday are blank; Monday–Friday carry the five-row bitmap font
- Typeface: custom pixel glyphs; M and W use five-column forms; I uses a full three-column serif-style bitmap
- Word spacing: two columns
- Lit pixels: 121
- Date mapping: each lit cell maps to its corresponding Monday–Friday date, starting Monday 4 January 1999
- No date is reused; all artwork dates remain inside 1999

The workflow uses a one-commit TEST gate before the full run. The full run refuses to execute without the TEST marker and refuses to run twice.
